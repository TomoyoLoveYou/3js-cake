# 🍰 卡通草莓蛋糕 · Three.js

用 Three.js 做的卡通风格生日蛋糕，单文件 HTML，浏览器打开就能看。

## 预览

直接打开 `cake/index.html`（需联网加载 Three.js CDN）。

## 技术要点

- **旋转曲面建模**：奶油裙、奶油盖、蕾丝盘、草莓全部由一条截面线绕轴旋转生成（`revolveSurface`），不是堆球体。边缘起伏是几何真实的波浪，不是贴图。
- **卡通渲染**：`MeshToonMaterial` + 4 段梯度贴图做硬边明暗分档；每个部件挂一层背面外扩描边。描边几何必须相对自身原点居中，否则缩放会变成位移。
- **程序化贴图**：海绵气孔、草莓籽用 canvas 实时生成（灰度图 × 材质色，换装只改颜色）。
- **手搓控制器**：不依赖 `examples/addons`，拖拽 / 滚轮 / 双指捏合 / 阻尼全部自己实现。
- **光照架构**：环境光只兜底（0.26），亮度交给主光（1.35），层次靠梯度贴图 —— 环境光拉高会洗白、丢层次。

## 交互

- 拖拽旋转，滚轮 / 双指缩放（竖屏自动拉远相机）
- 自动旋转开关
- 吹灭蜡烛（带烟雾粒子）
- 四套配色热切换：草莓奶油 / 抹茶白巧 / 香芋树莓 / 蓝莓星空
- 复位视角

## 目录

- `index.html` — 当前版本，单文件含全部代码

## 离线运行

Three.js 走 unpkg → jsDelivr → esm.sh 三个 CDN 依次兜底；三个都失败会显示引导提示。
若需完全离线，下载 `three.module.js` 后把脚本顶部 `CDN_LIST` 换成本地路径即可。
